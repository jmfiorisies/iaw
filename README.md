# IAW · Implantación de Aplicaciones Web

Manual de referencia del módulo 0376 (2º ASIR), construido con [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

**Contenido publicado en este repositorio:** Unidades 1 a 3 (Bloque RA1 — arquitectura web, protocolos
HTTP/TLS, Apache y Nginx). El resto de unidades del módulo se irán añadiendo progresivamente.

## Ver en local

```bash
pip install mkdocs-material
mkdocs serve
```

Abre `http://127.0.0.1:8000`.
