# Glosario Técnico

| Término | Definición |
|---|---|
| **ASGI** | Interfaz asíncrona servidor-aplicación para Python (sucesora de WSGI). |
| **CMS** | Content Management System — gestor de contenidos web. |
| **FastCGI** | Protocolo de comunicación entre servidor web e intérprete de lenguaje persistente. |
| **HSTS** | HTTP Strict Transport Security — fuerza HTTPS en el navegador. |
| **JWT** | JSON Web Token — token firmado que transporta reclamaciones (claims). |
| **MPM** | Multi-Processing Module — modelo de concurrencia de Apache. |
| **OCI** | Open Container Initiative — especificación estándar de imágenes de contenedor. |
| **PaaS** | Platform as a Service — plataforma de despliegue sin gestión de infraestructura. |
| **WSGI** | Interfaz síncrona estándar servidor-aplicación para Python (PEP 3333). |
