# 📝 Examen Final 1er Trimestre (UD1-UD6)

!!! danger "Convocatoria"
    **Duración:** 4h · **RA/Criterios evaluados:** RA1, RA5, RA6 completos

## Estructura de la prueba
1. **Bloque servidores (25%):** UD1-UD3 — arquitectura, Apache, Nginx.
2. **Bloque lenguajes de servidor (40%):** UD4-UD5 — PHP y Python, validación, sesiones, autenticación.
3. **Bloque datos y versionado (35%):** UD6 — SQL con PDO/consultas preparadas, Git.

## Caso práctico integrador
Se proporciona un enunciado de aplicación web con formulario, backend en PHP o Python (a elección
justificada del alumnado) y persistencia en MariaDB, desplegada tras un proxy Nginx con TLS. Se
evalúa el conjunto: seguridad, correcto funcionamiento y calidad del código entregado en un repositorio Git.
